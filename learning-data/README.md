# 学习档案

网站运行时会在此目录创建版本化 JSON 数据。请把这些文件与练习代码一起提交、推送。

- `profile.json`：历史进度恢复状态。
- `lessons/lesson-NN.json`：每课进度、自查项、面试回答与笔记。
- `sessions/<UUID>.json`：单次自动计时或手动补记；统计由有效记录计算。

不要在网站运行时执行 Git 拉取、切换分支或手动编辑这些文件。先保存并停止服务，再同步。
如果同一课程在两台电脑上都被修改，请在 VS Code 中比较并解决冲突。不要直接选择覆盖整个目录。
删除的时间记录采用软删除，以避免另一份旧仓库副本让它再次出现。
